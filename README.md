# About

Musik is an independent fork of Metrolist focused on providing a lightweight, clean, and community-driven YouTube Music experience for Android.

This project continues development separately while respecting and crediting the original Metrolist project and contributors.

# Features

## Playback
- Stream songs and videos directly from YouTube Music
- Background playback support
- Offline caching and downloads
- Skip silence
- Sleep timer
- Persistent queue
- Smart shuffle
- Gapless playback
- Audio focus handling

## Audio
- Built-in equalizer
- Audio normalization
- Tempo & pitch controls
- High-quality audio streaming
- Loudness adjustment
- Playback speed control

## Lyrics & Discovery
- Synced lyrics support
- Lyrics translation
- Word-by-word lyrics highlighting
- Quick picks and recommendations
- Search songs, albums, artists, playlists, and videos
- Trending music discovery
- Related songs suggestions

## Library
- Playlist management
- Local playlists
- Favorites and liked songs
- Queue management
- Playlist import support
- YouTube Music account sync
- Library backup & restore
- History support

## Interface
- Material 3 design
- Dynamic themes
- AMOLED dark mode
- Multiple color palettes
- Responsive UI
- Smooth animations
- Home screen widgets
- Landscape support

## Extra
- Android Auto support
- SponsorBlock integration
- Listen together support
- Discord Rich Presence
- Music recognition support
- Share songs with deep links
- Lightweight and optimized
- No ads
- Open source

# Building

## Requirements

- Android Studio
- JDK 21
- Android SDK

## Build Commands

### Universal

```bash
./gradlew assembleFossRelease
```

### ARM64-v8a

```bash
./gradlew assembleArm64Release
```

### armeabi-v7a

```bash
./gradlew assembleArmeabiRelease
```
